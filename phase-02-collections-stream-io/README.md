# Giai Đoạn 2: Collections, Stream Và I/O (Tuần 4-5)

## Mục Tiêu

Sau giai đoạn này, bạn hiểu cách chọn collection phù hợp, đọc được độ phức tạp cơ bản, dùng Stream vừa phải, xử lý date/time đúng, và đọc/ghi file bằng NIO.2.

## Tuần Học

- `week-04`: Collections internals và độ phức tạp.
- `week-05`: Stream, Optional, functional interface, `java.time`, NIO.2, log processing.

## Deliverable

Viết chương trình xử lý file log lớn bằng hai cách:

- Một bản dùng vòng lặp.
- Một bản dùng Stream.

Sau đó viết report so sánh về độ đọc, hiệu năng, memory và khả năng debug.
