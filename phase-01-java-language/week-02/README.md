# Tuần 2: Generics, Enum Và Nested Class

## Mục Tiêu Tuần

Tuần này tập trung vào các phần làm Java mạnh nhưng cũng dễ khó chịu lúc mới học: generics, wildcard, type erasure, enum giàu behavior và các dạng class lồng nhau.

## Lịch 8h

- Buổi 1, 2h: generics cơ bản, bounded type, generic method.
- Buổi 2, 2h: wildcard, PECS, type erasure.
- Buổi 3, 2h: enum, nested/static/inner/anonymous class.
- Buổi 4, 2h: làm generic repository hoặc LRU cache, viết test, AI review.
