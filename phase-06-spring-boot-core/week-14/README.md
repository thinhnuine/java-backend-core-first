# Module week-14: Từ In-Memory Sang PostgreSQL

Tên week-14 là mã module cũ. Học ở **tuần 12–15** theo [lịch 24 tuần](../../ROADMAP.md). Tổng thời gian dự kiến vẫn là 8 giờ/tuần cho các bài được chọn.
