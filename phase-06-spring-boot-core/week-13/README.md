# Module week-13: API Spring Đầu Tiên

Tên week-13 là mã module cũ. Học ở **tuần 7–8** theo [lịch 24 tuần](../../ROADMAP.md). Tổng thời gian dự kiến vẫn là 8 giờ/tuần cho các bài được chọn.

## Cần biết trước

HTTP, constructor injection và kiểm dữ liệu. Nếu chưa tự làm được, quay lại ví dụ trước thay vì đọc tiếp.

## Lượt học bắt buộc hoặc phạm vi được chọn

Tạo một API lưu tạm, chia controller/service/repository theo vai trò.

- [01-ioc-di-bean-autoconfiguration](01-ioc-di-bean-autoconfiguration.md)
- [02-rest-validation-error-handling](02-rest-validation-error-handling.md)

Mỗi lượt 15–25 phút: đọc một ý → tự gõ → đoán kết quả → chạy → sửa một đầu vào. **Qua bài khi:** Gọi tạo/lấy task và nhận đúng lỗi 400/404.
