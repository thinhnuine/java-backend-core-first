# Module week-13: API Spring Đầu Tiên

Tên week trong đường dẫn là mã tài liệu, không phải tuần theo lịch mới. Vị trí học: **tuần 7–8** trong [ROADMAP.md](../../ROADMAP.md). Mỗi tuần mới có tổng 8 giờ cho mọi tài liệu được chọn, không phải 8 giờ cho mỗi module.

## Cần biết trước

Java thuần/DI, HTTP contract và unit test.

## Lượt học bắt buộc hoặc phạm vi được chọn

Chạy /hello, theo request qua controller/service; xây Task API, validation/error và HTTP test.

Bắt đầu [bài thứ nhất](01-ioc-di-bean-autoconfiguration.md), sau đó [bài thứ hai](02-rest-validation-error-handling.md) theo phần roadmap chỉ định. Đọc một ví dụ → đoán output → tự chạy → đổi input → giải thích bằng lời của mình. Có thể dành thêm buổi khi chưa qua mốc; không đọc hết để chạy theo thời hạn.

## Đọc sau hoặc tự chọn

Bean lifecycle hooks và auto-configuration internals tra cứu sau; chưa cần JPA ở đây.
