# Giai Đoạn 6: Spring Boot Ở Mức Cốt Lõi (Tuần 13-14)

## Mục Tiêu

Dùng Spring Boot để build REST API nhỏ, nhưng hiểu những mảnh cốt lõi: IoC/DI, bean lifecycle, autoconfiguration, controller/service/repository, validation, JPA/Hibernate, transaction và integration test.

## Tuần Học

- `week-13`: Spring IoC/DI, autoconfiguration, REST API basics.
- `week-14`: JPA/Hibernate, transaction, N+1, final API project.

## Deliverable

Một REST API nhỏ như Task API hoặc Notes API:

- CRUD.
- Validation.
- Global error response.
- PostgreSQL + Flyway.
- JPA relationship đơn giản.
- Transaction ở service layer.
- Integration test cho endpoint chính.
- README chạy app và giải thích Spring đang tự động làm gì.
